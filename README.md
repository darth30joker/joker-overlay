joker-overlay
=============

It's a overlay for Gentoo for myself.

## how to use it?

1. Install `eselect-repository`:

    ```emerge eselect-repository```

2. Add JokerOverlay to repository list:

    ```eselect repository add JokerOverlay git https://github.com/darth30joker/joker-overlay.git```

3. Syncing JokerOverlay:

    ```emaint sync -r JokerOverlay```
